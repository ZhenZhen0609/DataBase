## 1. 项目概述

### 1.1 项目简介

本项目是一个完整的数据库管理系统（DBMS），实现了从底层存储到上层界面的完整技术栈，具备以下特性：

- **完整的 SQL 支持**：DDL（CREATE/DROP/ALTER）+ DML（SELECT/INSERT/UPDATE/DELETE）
- **完整性约束**：主键、外键、唯一、非空、CHECK、默认值
- **并发控制**：表级读写锁机制
- **索引优化**：哈希索引加速查询
- **事务支持**：BEGIN/COMMIT/ROLLBACK
- **数据安全**：SHA256 密码哈希、字段级加密
- **可视化界面**：Qt GUI、语法高亮、图表展示

### 1.2 开发团队分工

项目采用四人协作模式，按职责圈划分：

| 职责圈 | 团队 | 负责模块 | 核心文件 |

## 4. 存储机制详解

### 4.1 文件存储体系

系统采用**混合存储策略**，不同类型数据使用不同格式：

```
./data/
└── {username}/                          # 用户目录
    ├── users.json                       # 用户凭据（SHA256哈希）
    └── {dbName}/                        # 数据库目录
```

```cpp
// 密码哈希化（SHA256）
QString AuthManager::hashPassword(const QString &password) const {
    QByteArray hash = QCryptographicHash::hash(password.toUtf8(), QCryptographicHash::Sha256);
    return QString(hash.toHex());
}

// 登录验证：比对哈希值
bool AuthManager::login(const QString &username, const QString &password) {
    QJsonObject users = loadUsers();
    QString storedHash = users.value(username).toString();
    QString inputHash = hashPassword(password);
    return storedHash == inputHash;
}
```

```cpp
QByteArray RecordManager::serializeRecord(const QJsonObject &record, const QList<Field> &fields) {
    QByteArray data;
    QDataStream stream(&data, QIODevice::WriteOnly);
    stream.setByteOrder(QDataStream::LittleEndian);  // 小端序
    
    // 写入字段数量
    int fieldCount = fields.size();
    stream << fieldCount;
    
    // 依次写入每个字段的值
    for (const Field &f : fields) {
        QJsonValue val = record.value(f.name);
        
        switch (f.type) {
            case FieldType::INT:
                stream << val.toInt();
                break;
            case FieldType::DOUBLE:
                stream << val.toDouble();
                break;
            case FieldType::BOOLEAN:
                stream << val.toBool();
                break;
            case FieldType::TEXT:
                stream << val.toString();
                break;
        }
    }
    
    // 写入创建时间戳
    QString createdAt = record["_created_at"].toString();
    stream << createdAt;
    
    return data;
}
```

**反序列化实现**：
```cpp
QJsonObject RecordManager::deserializeRecord(const QByteArray &data, const QList<Field> &fields) {
    QJsonObject record;
    QByteArray mutableData = data;
    QDataStream stream(&mutableData, QIODevice::ReadOnly);
    stream.setByteOrder(QDataStream::LittleEndian);
    
    int fieldCount;
    stream >> fieldCount;
    
    for (const Field &f : fields) {
        switch (f.type) {
            case FieldType::INT: {
                int val;
                stream >> val;
                record[f.name] = val;
                break;
            }
            case FieldType::DOUBLE: {
                double val;
                stream >> val;
                record[f.name] = val;
                break;
            }
            case FieldType::BOOLEAN: {
                bool val;
                stream >> val;
                record[f.name] = val;
                break;
            }
            case FieldType::TEXT: {
                QString val;
                stream >> val;
                record[f.name] = val;
                break;
            }
        }
    }
    
    QString createdAt;
    stream >> createdAt;
    record["_created_at"] = createdAt;
    
    return record;
}
```

**读取所有记录**：
```cpp
QJsonArray RecordManager::readAllRecordsFromCache(...) {
    QJsonArray records;
    StorageManager storage;
    
    // 从缓存或磁盘读取整个 .trd 文件
    QByteArray data = storage.readTableData(username, dbName, tableName);
    
    QDataStream stream(&data, QIODevice::ReadOnly);
    stream.setByteOrder(QDataStream::LittleEndian);
    
    // 循环读取每条记录
    while (!stream.atEnd()) {
        // 读取记录大小
        qint64 recordSize;
        stream.readRawData(reinterpret_cast<char*>(&recordSize), sizeof(qint64));
        
        // 读取记录数据
        QByteArray recordData(recordSize, 0);
        stream.readRawData(recordData.data(), recordSize);
        
        // 反序列化并解密
        QJsonObject record = deserializeRecord(recordData, fields);
        decryptRecord(record, fields);
        records.append(record);
    }
    
    return records;
}
```

**写入所有记录**：
```cpp
bool RecordManager::writeAllRecordsToCache(...) {
    QByteArray data;
    QDataStream stream(&data, QIODevice::WriteOnly);
    stream.setByteOrder(QDataStream::LittleEndian);
    
    for (const QJsonValue &val : records) {
        QJsonObject record = val.toObject();
        
        // 加密敏感字段
        QJsonObject encryptedRecord = record;
        encryptRecord(encryptedRecord, fields);
        
        // 序列化
        QByteArray recordData = serializeRecord(encryptedRecord, fields);
        
        // 写入记录大小 + 记录数据
        qint64 recordSize = recordData.size();
        stream.writeRawData(reinterpret_cast<const char*>(&recordSize), sizeof(qint64));
        stream.writeRawData(recordData.data(), recordSize);
    }
    
    // 写入缓存和磁盘
    StorageManager storage;
    return storage.writeTableData(username, dbName, tableName, data);
}
```

### 4.3 缓存机制

系统实现了**内存缓存池**以减少磁盘I/O：

```cpp
// StorageManager 类中的静态缓存
static QHash<QString, QByteArray> dataCache;  // Key: "dbName_tableName"
```

**带缓存的读取**：
```cpp
QByteArray StorageManager::readTableData(const QString &username, const QString &dbName, const QString &tableName) {
    QString cacheKey = dbName + "_" + tableName;
    
    // 检查缓存
    if (dataCache.contains(cacheKey)) {
        return dataCache[cacheKey];  // 缓存命中，直接返回
    }
    
    // 缓存未命中，从磁盘读取
    QString trdPath = Config::dataPath() + username + "/" + dbName + "/" + tableName + ".trd";
    QFile file(trdPath);
    file.open(QIODevice::ReadOnly);
    QByteArray data = file.readAll();
    file.close();
    
    // 记录统计
    recordDiskRead();
    
    // 存入缓存
    dataCache[cacheKey] = data;
    return data;
}
```

**写入时同步缓存**：
```cpp
bool StorageManager::writeTableData(const QString &username, const QString &dbName, const QString &tableName, const QByteArray &data) {
    QString trdPath = Config::dataPath() + username + "/" + dbName + "/" + tableName + ".trd";
    
    // 写入磁盘
    QFile file(trdPath);
    file.open(QIODevice::WriteOnly);
    file.write(data);
    file.close();
    
    // 更新缓存
    QString cacheKey = dbName + "_" + tableName;
    dataCache[cacheKey] = data;
    
    recordDiskWrite();
    return true;
}
```

```cpp
QString ConstraintManager::xorEncryptDecrypt(const QString &input, const QString &key) {
    QString result;
```

```cpp
Response RecordManager::insertRecord(..., const QJsonObject &data) {
    // 1. 加载表结构
    QList<Field> fields = loadTableSchema(...);
    
    // 2. 默认值填充
    QJsonObject newRecord = data;
    for (const Field &field : fields) {
        if (!newRecord.contains(field.name) && !field.defaultValue.isEmpty()) {
            newRecord[field.name] = field.defaultValue;
        }
    }
    
    // 3. 类型验证
    Response validateResp = validateRecord(fields, newRecord);
    if (validateResp.status != ResponseStatus::OK) return validateResp;
    
    // 4. 加载已有记录
    QJsonArray existingRecords = readAllRecordsFromCache(...);
    
    // 5. 外键约束验证
    for (const Field &field : fields) {
        if (field.isForeignKey) {
            Response fkResp = ConstraintManager::validateForeignKey(...);
            if (fkResp.status != ResponseStatus::OK) return fkResp;
        }
    }
    
    // 6. 格式验证
    for (const Field &field : fields) {
        if (!field.formatValidation.isEmpty()) {
            Response formatResp = ConstraintManager::validateFormat(...);
            if (formatResp.status != ResponseStatus::OK) return formatResp;
        }
    }
    
    // 7. CHECK约束验证
    for (const Field &field : fields) {
        if (field.hasCheck) {
            Response checkResp = ConstraintManager::validateCheckConstraint(...);
            if (checkResp.status != ResponseStatus::OK) return checkResp;
        }
    }
    
    // 8. 唯一性验证
    Response uniqueResp = ConstraintManager::validateUnique(fields, existingRecords, newRecord);
    if (uniqueResp.status != ResponseStatus::OK) return uniqueResp;
    
    // 9. 获取写锁
    lockManager.acquireWriteLock(...);
    
    // 10. 写入
    existingRecords.append(newRecord);
    writeAllRecordsToCache(..., existingRecords);
    
    // 11. 释放写锁
    lockManager.releaseWriteLock(...);
    
    return {ResponseStatus::OK, "Insert success", QVariant(1)};
}
```

```
        ├──► 条件过滤（如有WHERE子句）
        │       │
        │       └──► ConditionParser::parse() ──► 构建条件树
        │               │
        │               └──► conditionTree->evaluate(record) ──► 逐条求值
        │
        ├──► 分组（如有GROUP BY）
        │
        ├──► 聚合计算（如有COUNT/SUM/AVG/MAX/MIN）
        │       │
        │       └──► computeAggregate()
        │
        ├──► 排序（如有ORDER BY）
        │
        └──► 分页（如有LIMIT/OFFSET）
```

### 6.3 双向依赖处理

**SQLParser ↔ QueryEngine 双向依赖**：

由于Parser需要调用Engine执行，而Engine处理嵌套查询时需要Parser，形成循环依赖。

**解决方案**：使用指针注入

```cpp
// SQLParser.h
class SQLParser : public QObject {
private:
    QueryEngine *m_engine = nullptr;
public:
    void setQueryEngine(QueryEngine *engine) { m_engine = engine; }
};

// QueryEngine.h
class QueryEngine : public QObject {
private:
    SQLParser *m_parser = nullptr;
public:
    void setParser(SQLParser *parser) { m_parser = parser; }
};

// MainWindow初始化
m_parser = new SQLParser(this);
m_queryEngine = new QueryEngine(this);
m_parser->setQueryEngine(m_queryEngine);
m_queryEngine->setParser(m_parser);
```

### 8.3 CMakeLists.txt 配置说明

```cmake
cmake_minimum_required(VERSION 3.16)
project(DBMS VERSION 0.1 LANGUAGES CXX)

# Qt元对象系统自动编译
set(CMAKE_AUTOUIC ON)    # .ui 文件自动生成
set(CMAKE_AUTOMOC ON)    # Q_OBJECT 类自动生成MOC代码
set(CMAKE_AUTORCC ON)    # .qrc 资源文件自动编译

# C++17标准
set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# 查找Qt（优先Qt6，兼容Qt5）
find_package(QT NAMES Qt6 Qt5 REQUIRED COMPONENTS Widgets)
find_package(Qt${QT_VERSION_MAJOR} REQUIRED COMPONENTS Widgets)

# 源文件列表
set(PROJECT_SOURCES
    main.cpp
    mainwindow.cpp mainwindow.h mainwindow.ui
    common.h
    storagemanager.h storagemanager.cpp
    authmanager.h authmanager.cpp
    schemamanager.h schemamanager.cpp
    recordmanager.h recordmanager.cpp
    sqlparser.h sqlparser.cpp
    indexmanager.h indexmanager.cpp
    lockmanager.h lockmanager.cpp
    queryengine.h queryengine.cpp
    conditionparser.h conditionparser.cpp
    constraintmanager.h constraintmanager.cpp
    datamigrator.h datamigrator.cpp
)

# 创建可执行文件
qt_add_executable(DBMS ${PROJECT_SOURCES})

# 链接Qt库
target_link_libraries(DBMS PRIVATE Qt${QT_VERSION_MAJOR}::Widgets)
```
